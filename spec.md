# UniResults Pro — Version 23

## Current State

UniResults Pro is a comprehensive university academic management system (V22) with:
- All 6 role dashboards fully integrated
- Senate Report tab (Registrar, HOD, Dean) with BSc/BSc Ed side-by-side display
- Departmental Results Processing (DeptResultsTab) with per-student grades, GP, GPA, CGPA, failed courses, and remarks
- Institution settings stored in localStorage under key `institutionSettings` (name, address, phone, email, website, logoText)
- Attendance tracking (AttendanceTab) — lecturers mark attendance per session with present/absent checkboxes
- Student and Staff ID cards with webcam capture and file upload
- Offline sync with status indicator, security validation, audit log
- QR scanner, camera integration already active

## Requested Changes (Diff)

### Add

1. **Level-separated report headings** — In both SenateReportTab and DeptResultsTab, separate results by level (100, 200, 300, 400) with a full institutional heading above each level section:
   - Line 1: Institution name (from `institutionSettings.name`, defaulting to "Federal University of Education Kontagora, Niger State")
   - Line 2: Faculty name
   - Line 3: Department name
   - Line 4: "LEVEL [100/200/300/400] STUDENTS"

2. **Biometric Attendance Module** — New tab `BiometricAttendanceTab` (accessible to Lecturers, HOD, Registrar, Dean):
   - When marking attendance, lecturer can optionally capture a webcam photo per student (click "Capture" for each student row)
   - Photo is stored in localStorage as base64 keyed by `biometric_{sessionId}_{studentId}`
   - Attendance record includes optional `biometricPhoto: string | null`
   - A "Biometric Log" view shows a grid of captured photos per session with student name, date, and status badge
   - Filtering by course, date range, and student

3. **Biometric Attendance Login Dashboard** — SuperAdmin and Registrar see a new "Biometric Dashboard" section showing:
   - Total biometric check-ins today
   - List of students/staff who have checked in with timestamp and photo thumbnail
   - Filter by role (student/staff), department, date

4. **Security Camera / Camera Permissions Panel** — New settings tab "Camera & Security" in SuperAdmin and Registrar Settings:
   - Toggle permissions per role: who can use webcam (Students, Lecturers, HOD, Dean, Registrar, SuperAdmin)
   - Live camera preview (start/stop) for security monitoring purposes
   - Camera access log: when webcam was activated, by which role, with timestamp (stored in localStorage)
   - Camera permission settings saved to localStorage under `cameraPermissions`

5. **Enhanced photo upload for Staff** — In StaffTab, each staff member can have a photo captured via webcam or file upload, stored similarly to student photos under `staff_photo_url_{staffId}`

6. **Report Monitoring Dashboard** — New tab "Report Monitor" (SuperAdmin, Registrar):
   - Lists all generated reports (Senate, Departmental Results) with timestamp, generated by, department, and export count
   - Reports are logged to localStorage under `reportActivityLog` each time a report is printed/exported
   - Filter by report type, department, date range

### Modify
